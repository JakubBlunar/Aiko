# Memory grounding rollout — 5 November 2026

Implements the [producer audit](memory-producer-audit-2026-11-05.md) in bounded
slices. Source meaning must survive into Aiko's knowledge while her own declared
preferences, reflective inner life and virtual experiences remain available.

## 1. Source roles and concept admission

`memory_origin.py` supplies a shared subject/mode/domain/writer interpretation.
New accepted memory inserts retain a versioned origin in metadata. Old records
are interpreted using their existing producer-kind contract without rewriting
them or manufacturing missing message roots. Validated user admission wins over
first-person grammar; ambiguous legacy first-person self-tags remain unknown.
Explicit malformed contracts fail closed. Origin changes affect source revisions,
while unchanged legacy rows retain the exact previous revision algorithm.

The existing lineage diagnostic uses this same interpretation. Its evidence
independence counts remain shadow-only; source-role eligibility is now enforced
separately by synthesis admission. These are different checks.

New proposals and reinforcement cannot cite hypothetical drafts, unanswered
questions, derived topic summaries or world facts as personal observations.
Aiko-owned progress/reflection/activity notes cannot establish a user claim.
Future plans and promises cannot supply completed narrative steps. Proposer
memory lines carry subject, mode, domain, provenance and known event/status
fields, distinct from recording age.

Cluster subjects follow resolved personal origins instead of treating every
kind outside self/reflection/diary as user-owned. World-only clusters have no
personal subject. Cluster-based identity/value admission checks all cited members,
including missing sources; a mixed cluster cannot authorize an incompatible row.
This is intentionally conservative and can defer otherwise plausible cluster
claims. Ordered narratives/aspirations can still use eligible individual members
of a mixed cluster, subject to their original evidence/age requirements.

Ordinary memory retrieval is unchanged: public knowledge remains usable for world
questions, drafts remain drafts and Aiko's own notes can support her self-model.
No historical memory or concept is deleted or silently certified. Concept-over-
concept evidence retains its existing dependency checks; this slice does not
retroactively adjudicate the semantic quality of historical parent concepts.

The three inspected audit failures are refused by the shared production policy:
the drafted consultation, Aiko goal reflections presented as user experience,
and public cookie facts presented as user actions. Synthetic persistence tests
also retain real user records, Aiko self-declarations/reflections, virtual activity
and joint observations. This establishes role boundaries, not general entailment.

Validation: 625 affected tests and 48 subtests passed, with 7,244 unrelated tests
deselected; `npm run lint` passed. The representative set covers memory storage,
temporal/provenance behavior, lineage/dependency races, synthesis/retries,
narrative/aspiration, scoped styles, boundaries, generalization and pursuits.
Older fake clusters were corrected to contain actual source rows instead of
accidentally citing Aiko notes as user sources. No full-suite or live model-quality
claim follows. Private audit artifacts remain in the ignored audit directory.

## 2. Preserve source scope through storage and merging

Insert-time dedupe now compares subject, mode, domain, provenance and temporal
scope before cosine similarity. Known event dates must agree; undated past
events/ongoing episodes cannot be collapsed just because their wording matches.
Recent undated plan restatements retain their existing dedupe behavior. Explicit
user correction links still survive across different provenance labels.

Automatic content rewrites become inferred interpretations, preserve their
original subject and retain two bounded prior wording/revision receipts. Metadata
edits do not downgrade testimony. Manual edits explicitly retain curated stated
authority. Insert and update share temporal validation; relative wording no
longer manufactures an event timestamp equal to the recording timestamp.

Both consolidators require compatible source roles, authority and time scopes.
Reflective journals, hypothetical drafts and intentions are not merge candidates.
The older consolidator now archives original sources instead of deleting them,
keeps their concept edges attached to the original evidence and stops counting a
merge as an actual use. Changed text requires re-embedding, and synthesized
confidence does not exceed the weakest input. Merge receipts retain source IDs
and revisions. Archival remains retention policy, not a truth judgment.

Validation: 188 focused tests passed, then 557 affected tests passed with 6,908
deselected; lint passed. The affected selection exercises storage, consolidation,
temporal/provenance rules and concept dependencies; it is intentionally bounded
despite the store's broad static import reach. These are synthetic regressions,
not a claim that all historical rewrites have been repaired.

## 3. Dated inner-life and conversation workers

Goal workers now receive today's anchor, storage rules and dated reflection
history. Their prompt distinguishes intentions/reflections from evidence of
completed actions and permits abstention. Goal reflection and away-diary writes
reject unanchored relative wording. Diary transcripts preserve dates and actors
when trimming input; entries are Aiko's episode reflections, with unknown event
times left unknown. This does not turn reflection into an action-verification
system: the role guard from slice 1 remains necessary.

Dream inputs were already age-tagged at the source, but truncation inside the
dream prompt could cut the age suffix off long notes. Content is now bounded
before formatting and the age survives. Creative private reflections remain
available, with an explicit distinction from experienced or completed events.

Shared-moment scheduling now passes real message rows rather than discarding
their IDs/dates into `(speaker, text)` tuples. The bounded offered window retains
its IDs as a `context_window` receipt, explicitly not per-claim quote proof. A
known conversation timestamp supplies canonical event time; absent dates remain
unknown, separate from the display's recording-time fallback. Manual date edits
update the canonical fields too. The weekly relationship pulse now writes an
Aiko-owned `self` reflection rather than a user-oriented `self_tagged` note.
No legacy self-tag cohort was bulk-renamed.

Validation: 213 affected tests passed with 2,940 deselected, plus focused final
moment/date checks; lint passed. Dynamic scheduling and long-input age retention
have explicit regression coverage.

## 4. Source-grounded promises

The extractor now requests a message ID and literal quote alongside each action.
Only IDs in the actual bounded offered transcript, a matching speaker and a
matching quoted span can populate the source pointer. Missing/invented citations
and floating relative wording cannot be persisted by this worker. This checks
attribution, not full semantic entailment of the paraphrased commitment.

Relative deadlines resolve against the cited message's timestamp rather than
the later extraction time. Stored deadline labels always include their year.
Promise status/deadline remain the lifecycle authority, separate from ordinary
event-expiry fields. Duplicate detection is scoped by actor and known deadline;
the same action promised by Aiko and the user cannot suppress one another.

The privacy gate still checks actual conversation text, before infrastructure
timestamps/IDs: ISO stamps can resemble phone numbers to the PII detector.
Standalone legacy JSON parsing remains tolerant; production extraction requires
the source map. No old promise was retroactively assigned a fabricated citation.

Validation: 117 focused tests and 25 subtests passed. The broad affected run in
the project's environment passed 1,657 tests and 147 subtests, with one unrelated
audio timing failure; the focused follow-up (including that audio file) passed.
The system Python initially lacked the declared timezone-data dependency; the
project environment supplied it. Lint passed.
