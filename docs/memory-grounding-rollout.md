# Memory grounding rollout — 5 November 2026

Implements the [producer audit](memory-producer-audit-2026-11-05.md) in bounded
slices. Source meaning must survive into Aiko's knowledge while her own declared
preferences, reflective inner life and virtual experiences remain available.

## 1. Source roles and concept admission

`memory_origin.py` supplies a shared subject/mode/domain/writer interpretation.
New accepted memory inserts retain a versioned origin in metadata. Old records
are interpreted using their existing producer-kind contract without rewriting
them or manufacturing missing message roots. Validated user admission wins over
first-person grammar; ambiguous legacy first-person self-tags remain unknown.
Explicit malformed contracts fail closed. Origin changes affect source revisions,
while unchanged legacy rows retain the exact previous revision algorithm.

The existing lineage diagnostic uses this same interpretation. Its evidence
independence counts remain shadow-only; source-role eligibility is now enforced
separately by synthesis admission. These are different checks.

New proposals and reinforcement cannot cite hypothetical drafts, unanswered
questions, derived topic summaries or world facts as personal observations.
Aiko-owned progress/reflection/activity notes cannot establish a user claim.
Future plans and promises cannot supply completed narrative steps. Proposer
memory lines carry subject, mode, domain, provenance and known event/status
fields, distinct from recording age.

Cluster subjects follow resolved personal origins instead of treating every
kind outside self/reflection/diary as user-owned. World-only clusters have no
personal subject. Cluster-based identity/value admission checks all cited members,
including missing sources; a mixed cluster cannot authorize an incompatible row.
This is intentionally conservative and can defer otherwise plausible cluster
claims. Ordered narratives/aspirations can still use eligible individual members
of a mixed cluster, subject to their original evidence/age requirements.

Ordinary memory retrieval is unchanged: public knowledge remains usable for world
questions, drafts remain drafts and Aiko's own notes can support her self-model.
No historical memory or concept is deleted or silently certified. Concept-over-
concept evidence retains its existing dependency checks; this slice does not
retroactively adjudicate the semantic quality of historical parent concepts.

The three inspected audit failures are refused by the shared production policy:
the drafted consultation, Aiko goal reflections presented as user experience,
and public cookie facts presented as user actions. Synthetic persistence tests
also retain real user records, Aiko self-declarations/reflections, virtual activity
and joint observations. This establishes role boundaries, not general entailment.

Validation: 625 affected tests and 48 subtests passed, with 7,244 unrelated tests
deselected; `npm run lint` passed. The representative set covers memory storage,
temporal/provenance behavior, lineage/dependency races, synthesis/retries,
narrative/aspiration, scoped styles, boundaries, generalization and pursuits.
Older fake clusters were corrected to contain actual source rows instead of
accidentally citing Aiko notes as user sources. No full-suite or live model-quality
claim follows. Private audit artifacts remain in the ignored audit directory.
